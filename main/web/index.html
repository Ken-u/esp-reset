ESP Reset

无线硬件复位控制器

连接控制器

管理密码：esp32reset。也可通过 USB 脚本查询。

三路独立 RESET

每路通过自己的外部开关，控制对应开发板的 RESET 按键。

每路脉冲约 200 ms，松开后独立冷却 3 秒。成功回执表示按键已松开，目标系统的启动状态需要另外确认。

Loader / Maskrom 组合

仅用于同一目标板：第1路接 RESET，第2路接 RECOVERY，第3路接专用 MASKROM。先按模式键100ms，再按 RESET 200ms，松 RESET 后继续保持模式键。

Wi-Fi 配网

开放网络可留空；修改已有网络时也需重新填写密码。

固件升级

上传与本机芯片匹配的 esp-reset 应用固件 .bin。升级完成后控制器自动重启，Wi-Fi 和管理密码保留。

控制器维护

重启这台 ESP 控制器。更换网络或忘记 Wi-Fi 时，运行中长按板载 BOOT 约 5 秒可清除 Wi-Fi，随后通过 USB 脚本重新配网。

复位输出必须通过外部 MOSFET 或隔离干接点开关接到目标按键。通过 USB 配网，AP 已关闭。
